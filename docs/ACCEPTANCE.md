# 验收清单

以下区分自动测试可证明的服务行为与必须在真实浏览器 / 第二账户手动确认的工作流。不要把静态扩展检查或本地 MCP 调用成功描述为已经完成所有账户接入。

## 自动验证

```powershell
.\scripts\Test.ps1
```

核对测试覆盖：导入与幂等重导、分支 / 工具记录、损坏输入与来源报告、搜索与分页、消息修订、带来源交接、工程文件过滤 / 修订、实时增量入库、源轮询、一致性备份与空目录恢复、坏路径拒绝、HTTP Host / Origin / Bearer / CSRF、MCP 工具约束。具体通过数量以实际命令输出为准。

扩展测试检查 Manifest 权限、固定回环目标、无 Cookie / 私有接口使用、队列边界，并在本机有 Node.js 时执行 `node --check`。这只证明静态契约 / JavaScript 语法。

测试用 `tempfile.mkdtemp` 保留临时证据目录，不使用 `TemporaryDirectory` 自动递归清理；没有自动删除测试材料的操作。首次环境需执行 `Setup.ps1` 安装可选 MCP / 加密依赖才能运行相关依赖测试。

## 浏览器实测

1. 启动本地仪表盘，加载扩展并配对，使用唯一账户标签 / 测试项目。
2. 打开真实 `/c/<id>` ChatGPT 聊天，发送可识别短句；数秒后搜索该短句，核对账户 / 项目 / 角色 / 原文。
3. 观察一段流式回复，确认最后完整文本成为活动版本且旧修订仍保留。
4. 页面刷新、切到另一稳定聊天、返回原聊天，确认正常持续采集。若 DOM 缺少消息 ID，记录 fallback 去重限制。
5. 停止服务，发送测试消息，弹窗出现待发送队列 / 错误；重新启动服务，点击立即重试，确认队列归零、消息可搜索。
6. 暂停扩展，切换 Plus 账户并更新标签，重新启用后发送测试，核对两个账户标签均保留。
7. 确认首页 / 无稳定会话 ID 不新增虚假会话，隐藏 / 未渲染消息不被声称已收集。
8. 弹窗填写原项目 / 主题名称，点击“读取本地记忆”，核对检查点与引用；点击复制后粘贴到新账户聊天，确认没有自动发送。归档暂停时仍能明确读取。

## Codex 与工程实测

配置允许的 Codex 来源与测试工程，保持同步服务运行。新增一条 Codex 对话并修改一个允许的工程文件，等待一个同步周期，再搜索对话、读取归档文件并核对修订。核对报告列出的排除 / 超限文件，确认来源未被修改。

持续来源的原始 Codex JSONL 应先保存完整快照，再对已验证前缀保存追加后缀与 SHA256 链清单；核对新增消息入索引、未变消息不重复、改写文件退回完整快照。首次大导入以扫描完成状态为准，不以固定 3 秒超时判断失败。未指定项目时检查 `cwd` 目录名推断及同名路径限制。

追加完整检查点；另一个 Codex 账户由用户安装本地 MCP 配置，调用 `resume_project`，检查目标 / 决策 / 下一步是否一致，再读取相关原文和归档文件。要求模型在实际工程目录工作；归档副本不是运行工程目录。

## 普通 ChatGPT 第二账户实测

在扩展读取并复制最新交接内容，粘贴到另一账户；也可导出新交接文件上传。请求它复述当前目标、已完成事项、关键决策、阻塞和下一步，与最新检查点对照。让扩展用该账户标签保存新聊天，再追加检查点并读取下一个交接包。此路径无需 API Key，需要一次明确读取与粘贴 / 上传操作。

如果测试直接调用 MCP 的 ChatGPT 客户端，应记录客户端 / 套餐 / 插件能力、实际网络接入与授权方式，分别确认搜索、续接、引用、拒绝越权和写检查点边界；本工程不自动申请远程账号权限。

MCP 读取长消息时核对 `fetch_thread` 的正文预算与截断标记，再以消息 ID 调用 `fetch_message` 逐字符偏移取完各块；确认没有任意路径读取、完整原始档案或重复历史指令元数据泄漏。

## 备份实测

备份到新路径，恢复到新空目录，运行审计并对比对话 / 消息 / 项目计数。安装加密依赖时测试正确密码恢复及错误密码拒绝。已有库 / 已有输出不覆盖。原始来源哈希一致，备份不包含登录凭据。所有证据保留，不执行批量删除。

验证当前实现没有创建明文备份暂存数据库 / ZIP 或恢复校验临时文件；普通备份直接写目标，加密备份 / SQLite 校验使用受限内存。运行库和恢复后的数据库默认仍为明文，不能把加密备份理解为整机资料加密。

恢复后核对 `sources list` 中的 `needs_confirmation`；执行同步应跳过这些来源，不打开归档携带的本地路径。用户明确重新添加相同来源配置后再核对同步恢复；原运行库来源状态不应因新目录恢复而改变。

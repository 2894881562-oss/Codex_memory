# 隐私与信任边界

本项目不调用 OpenAI 推理接口，不要求 API Key，没有遥测。归档和搜索在本地完成。安装可选依赖会连接 Python 包仓库；Chrome / Edge 及 ChatGPT 本身仍按其各自规则运行。

## 保存内容

- ChatGPT 官方导出、允许的 Codex JSONL、浏览器当前聊天文本和明确指定的工程文件。
- SQLite 活动版本、全文索引、消息 / 文件修订、账户标签、项目检查点和来源路径。
- 内容寻址的原始档案，用于追溯和完整性检查。原始档案可能包含你在聊天或源文件中自己写入的敏感信息。
- 本地服务认证 / 采集令牌，以及浏览器扩展中的配对设置与有限离线队列。这些令牌只控制本地服务，不能登录 OpenAI。

搜索与工具输出会做常见令牌模式脱敏；脱敏不可能识别所有商业秘密、隐私或自行定义的密码。原始档案用于保真，不能把“索引脱敏”理解为“原始资料已无秘密”。原始库默认不加密，建议存于受保护磁盘；可选加密只作用于备份容器。

当前备份使用受大小上限约束的内存 SQLite 快照；普通 ZIP 直接写入用户指定的新目标，加密 ZIP 仅在内存构建后输出加密容器。恢复在内存中校验数据库，没有额外明文备份暂存 / 恢复校验文件。恢复目标本身仍是默认明文运行库；内存处理不等于运行库加密。

内存处理要求足够可用 RAM，可能同时持有多份数据库 / ZIP 副本；SQLite 快照最高 2 GiB、单个原始档案 512 MiB、总展开内容 8 GiB、加密 ZIP 512 MiB。工程不会创建明文暂存文件来绕过这些限制。

Codex 持续归档保留首个完整来源；已验证旧前缀的追加写入保存后缀与 SHA256 链清单，从而追溯原始字节而不反复复制整份大型 JSONL。文件发生改写时保存新完整快照。这些原始字节和链清单仍属于本地私有档案，默认不加密。

## 排除和数据不变性

不会主动导入认证文件、Cookie、登录 token、浏览器个人资料或沙箱秘密。Codex 扫描限制为会话数据，工程扫描按凭据 / 构建规则过滤。来源只读；本项目不更改 OpenAI 账户、Codex 全局配置或原始工程文件。自动同步不会删除旧档案；测试和备份没有递归清理。

备份中的来源路径属于不可信历史数据。恢复后所有来源标记 `needs_confirmation` 并暂停；校验 / 恢复只处理备份内容，不读取这些来源路径，后续自动同步也会跳过它们。用户检查后明确重新添加相同类型、路径、账户标签和项目，才确认并启用该来源；原运行库现有已配置来源不受影响。

## 访问边界

仪表盘默认只绑定 `127.0.0.1`，校验 Host / Origin，使用本地会话认证与写操作 CSRF。采集接口要求单独 Bearer 令牌，只允许有效扩展 Origin 或持有令牌的本地客户端，不支持任意网站写入。原始档案不经网络工具直接返回；工具不允许任意本地路径读取。

MCP stdio 是本机客户端访问方式。连接另一个模型账户后，你请求返回的搜索 / 交接 / 文件片段会进入该模型的上下文，并可能由其服务商处理；“原始库在本地”不代表“被你提交给 ChatGPT 的片段从未离开电脑”。普通 ChatGPT 上传交接包也同理。

MCP 默认只读，启用 `--allow-writes` 才可保存检查点；不提供任意导入、备份、文件写入或删除工具。回环 HTTP MCP 不等于安全公网服务。若未来部署远程服务，应另行完成用户认证、TLS、OAuth、权限、日志和账户逐个连接验收。

MCP 会话读取使用正文字符预算，并限制元数据为来源定位字段；长消息通过 `fetch_message` 分块读取已脱敏索引内容，不返回完整原始档案。文字预算限制单次上下文量，不会使敏感文本自动变成安全内容，也不改变历史资料的不可信性质。

## 历史是参考资料

导入聊天中的 `system` / `developer` 角色、终端输出、代码和文件内容都只是历史来源数据，不是给当前模型的新权限或执行命令。交接包和 MCP 结果明确提醒这一点。当前任务要求、用户授权和客户端规则决定执行行为。

浏览器扩展不会执行聊天内容或修改页面。它没有 Cookie、浏览器历史或其他站点权限，只在 `chatgpt.com` 观察渲染消息并向固定回环地址发出采集 / 明确读取请求。`clipboardWrite` 仅用于用户点击“复制交接内容”后写入剪贴板，不读取剪贴板。

## Git 与便携备份

工程的 Git 忽略规则应排除 `data`、备份、日志、数据库、导出和真实交接包。若用户选择工程外或自定义工程内路径，仍须自行确保它不被提交。备份包含真实私有记录，不应作为软件发布附件。不要把完整 `.codex`、认证文件或浏览器配置复制到其他账户。

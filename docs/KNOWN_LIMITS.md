# 覆盖范围与已知限制

## “全部”和“无缝”的边界

本工程提供账户独立的归档和上下文检索，可以让另一账户继续已保存的任务与聊天。不能自动恢复 OpenAI 原生侧栏、已删除消息、云端 Memory、GPT 配置、插件授权或订阅。保存到本地也不会取消 ChatGPT / Codex 原服务的数据保存。

没有个人 ChatGPT 全量历史实时接口。本工程用官方导出补历史，用浏览器扩展采集当前打开的聊天，用本地会话 / 工程轮询更新 Codex。未打开页面、手机、桌面原生 ChatGPT、临时视图、虚拟滚动未渲染内容、未选择分支、图片和附件原文件，不属于 DOM 实时覆盖。完整导出的覆盖仍取决于 OpenAI 实际提供了什么。

换账户也需要给模型提供检索入口或交接包：本机 Codex 可通过 MCP 读取；普通 ChatGPT 可在扩展点击“读取本地记忆”后复制粘贴，或上传交接文件。这需要明确点击 / 提供上下文，不是云端模型自动读取全部磁盘。云端 ChatGPT 不能仅凭知道本机文件路径或 `127.0.0.1` 地址就访问它。本工程未自动部署公网 MCP、OAuth 或安装账户插件，不声称第二账户接入已经验证。

## 浏览器采集

当前扩展版本 0.3.0。升级后重新加载扩展并刷新目标聊天页；旧页面不能自动采用新的账户标签。服务在线由当次探测确认，与过去写入成功、页面已经观察到多少内容分别展示，不能据在线状态推断数据完整。

- 使用稳定 `/c/<id>` 地址；尚未获得稳定地址的新聊天等地址出现后才采集。首页 / 无稳定 ID 的临时聊天不导入。
- 依赖 ChatGPT 页面 DOM 的 `data-message-author-role` / `data-message-id` 和正文选择器。OpenAI 改版可能需要调整；没有绕过页面去读私有后台接口。
- 无消息 DOM ID 时使用该实际 DOM 节点的本次加载身份，元数据明确标注 fallback。页面重载 / 虚拟化替换节点可能重复归档，不保证严格去重。
- MutationObserver 与 10 秒兜底观察、服务端轮询不是零延迟。后台标签页节流、流式生成、服务挂起和网络恢复会增加延迟。以最近成功保存时间为准。
- 已观察但未渲染 / 隐藏的消息不采集。缺少消息不会删除既存记录；DOM 当前选中分支不代表全部分支。
- 离线队列上限 100 批 / 6 MB，单批 4 MB；满队列和超限显示错误。离线同一条回复合并为最新文本，不保留每个中间 token。
- 扩展禁用、浏览器关闭、退出账户或离开页面前，未进入持久队列的 DOM 变化可能丢失；重开可见聊天或官方导出可补齐。扩展升级后刷新页面。
- 账户标签与项目由用户填写；没有读取登录身份自动判断账户。先点击暂停才能换标签，保存新标签仍暂停；旧队列保留原标签，可以手动重试。关闭旧页面、切换网页账户，确认启用并刷新目标页。相同标签下自行切换登录身份仍无法被软件识别，正确标签依赖用户确认。

## 官方导出与附件

ZIP / 目录仅将 `conversations.json` 和 `conversations-数字.json` / `conversations_数字.json` 识别为聊天文件；不猜测任意 JSON。明确选择单个 JSON 时仍可解析已支持的结构。数字分片按稳定顺序处理，不支持的结构与空正文保留原件并报告。所选导出的 complete 表示受支持内容已解析，而不是全账户 / 全分支 / 原生 Memory 的覆盖保证。

附件引用只在已导入的原始文件中寻找唯一关联，记录原件路径和 SHA256；名字 / 路径歧义不会随便选一个。远端 URL 不下载，引用缺失或达到检查上限报告 partial。关联不是 OCR、语音识别或图像语义理解，原件不会自动进入云端模型上下文。附件检查结果按引用、导出父目录与显式名称证据去重计数，不等于原件数量；`attachments_available` 才是可用原件数。单条消息索引只保留有界的引用和关联摘要，完整原件仍在本地档案。

报告最多展示 200 条有界警告并提供省略数量；有省略不视为全量无误。解析数量与新增数量不同：旧快照或重复导入可以新增为零，仍能搜到既存历史。最新导出覆盖与最近实时入库时间独立保留，后来的 DOM 消息不会抹掉导出诊断；0.2 旧报告没有覆盖字段时不能据此猜测完整性。

## 数据及工程同步

Codex 内部 JSONL 格式可能变化；不支持的记录留存原始来源并报告。未落盘 / 无本地记录的云端任务不能保证收集。一个本地会话目录可能包含多个登录账户，来源标签并非 OpenAI 身份核验。

未指定项目标签时按 Codex 会话 `cwd` 目录名推断，同名的不同路径会共用标签；显示标签不是工程目录的唯一身份。明确指定项目可覆盖推断，但对混合来源指定一个标签会合并该次来源内所有会话的归组。

默认轮询在上轮结束后等待 3 秒再开始；较大的首次导入可能耗时数分钟，不能承诺固定 3 秒保存延迟。Codex 持续扫描按文件变更选择候选，验证旧前缀后把新增原始字节和 SHA256 链清单归档，索引只提交新增行；正确去重仍依赖解析整个变更文件，后续大文件也不一定是恒定时间操作。重写 / 截断会退回完整快照保存，官方历史导入不是实时逐行接口。

工程归档仅覆盖明确配置、规则允许且未超限的文件，Git 模式主要覆盖跟踪文件。Git / 代码归档不能代替运行环境、数据库、外部服务授权或真实部署状态。没有自动恢复并覆盖工程文件功能。

Git 快照保存 HEAD、分支、状态和文件哈希 / 内容，没有完整 `git diff` 或 Git 提交对象归档；保留真实 Git 仓库的备份仍有必要。

检查点不会自动推断“最后正在做什么”；实时聊天和工程保存不等于语义准确的任务进度。字段可以由用户填写，但 API 只追加记录，修改 / 纠正通过新检查点表达，旧检查点不覆盖。阶段结束应追加结构化检查点，让另一账户可以准确续接。

全文检索无需模型 API，但没有语义向量模型；近义改写不一定命中。使用关键词、项目 / 账户筛选与来源引用判断结果。交接包有长度限制，只精选上下文；全部原文需分页检索。不同模型的上下文窗口、推理差异和用户上传能力影响续接效果。

任务相关交接使用字面关键词、中文字符 n-gram 和检查点锚点，不是语义理解或中文分词器。候选查询及展开均有数量上限；很常见的短词会退回 LIKE 扫描，可能较慢或漏掉候选上限以外的旧决定。优先输入数个具体关键词并按消息 ID 核对。最短交接包无法同时容纳所有记忆、检查点、证据和文件信息；会显示省略 / 摘录标记。没有 token 精确预算。

默认交接优先选用户 / 助手正文，不把推理、开发者配置、工具调用参数或不透明事件作为聊天证据；无匹配对话时可后备用工具输出。相同角色且窗口正文相同的重复证据只选一个来源，原始归档不会合并删除。工具参数的工程审计仍可通过显式搜索与按 ID 核对；交接不是所有工具活动的全集。

个人记忆的 confirmed 仅证明操作者选取了存在、角色为 user 的原话，不自动证明摘要正确、身份真实或偏好永不过时。记录按 key+项目追加修订，与账户标签无关；最新 proposed/withdrawn 不回退旧 confirmed。全局和项目记录同 key 时可能语义冲突，调用方必须核对范围和最新用户要求，软件不自动裁决。默认最多返回100条，稳定键总上限512；索引库及来源档案必须保留。撤回不会删除旧版本、备份或已分享内容。

目前没有完整原始 append 链回放 / 全索引重建命令；数据库还包含权威检查点、版本与来源授权，不可按“可重建缓存”随意删除。参考架构与未来验收见 [REFERENCE_DESIGN.md](REFERENCE_DESIGN.md)。

MCP `fetch_thread` 的正文也有总字符预算，可能把较长消息截断，即使本页消息数未达上限。继续读取需按内部消息 ID 调用 `fetch_message` 的字符分块，检查 `has_more`；这些是已脱敏索引正文，不是未经处理的原始档案。工具元数据仅返回有限来源定位字段，但历史正文仍是不可信参考。

## 网络接入与可移植性

默认回环服务只适用于同一电脑。普通 ChatGPT 上传交接包不要求 API Key。本地 Codex stdio MCP 也不要求 API Key。ChatGPT 远程 MCP 需要可达端点和客户端权限，本工程的本地 Bearer HTTP 不是完整云端 OAuth 接入产品。

截至 2026-10-04 检查的[官方 MCP 接入指南](https://developers.openai.com/plugins/build/app-quickstart)说明远程 HTTPS 路线；[官方 Secure MCP Tunnel 文档](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)要求运行时 API Key。后者不属于这个“用户没有 API Key”的默认方案。套餐可用性和界面可能变化，实际每个账户必须验收。

备份用于搬迁 / 恢复本地库，不移植登录。新电脑需重新配置来源路径、扩展配对及 MCP 入口。在线快照避免 SQLite 热复制不一致；加密备份依赖可选 `cryptography`，原始运行库默认不加密。SQLite 快照 / 恢复校验在内存完成，加密 ZIP 也在有上限的内存构建，不创建额外明文暂存文件。

恢复库中的来源全部暂停为 `needs_confirmation`，即使在同一电脑也不会立即重新扫描旧路径。用户必须检查并按同一类型、路径、账户标签及项目重新添加来确认；新路径可另行配置，旧条目保持暂停。读取已有归档 / 交接包不需要启用来源，实时更新则需显式确认。

SQLite 快照上限 2 GiB，单个原始档案上限 512 MiB，总展开备份 / 恢复内容上限 8 GiB，加密 ZIP 上限 512 MiB。峰值 RAM 可能包含多份 SQLite / ZIP 副本，显著高于单个数据库文件大小；这些是输入限制，不是内存用量保证。大库操作前需确保足够可用内存，内存不足仍可能失败；不会通过明文磁盘暂存规避内存上限。

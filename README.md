# Codex Memory Local

将多个 ChatGPT / Codex 账户的聊天和工程资料归档到同一份本地记忆库，再通过全文搜索、项目检查点和交接包继续工作。无需 OpenAI API Key，不调用模型推理 API；你的 Plus 使用方式不需要改变。

换到另一个账户后，先读取 [CONTINUE.md](CONTINUE.md)；这是本工程的续接入口，说明共同记忆库的位置、读取方式和实时更新前提。

已经提供：ChatGPT 官方导出导入、Codex 本地 JSONL 会话导入、原始资料留存、SQLite 全文搜索、项目文件与版本归档、定期轮询同步、ChatGPT 浏览器实时采集扩展、本地中文仪表盘、MCP 读取工具、带来源的交接包、一致性备份 / 新目录恢复和可选密码加密备份。

0.2 增加有用户原话来源的个人记忆（提议 / 确认 / 撤回与修订），以及按当前任务、检查点和较早相关证据生成的交接包。新账户应先核对确认记忆，再按当前请求续接；不会从旧助手回复自动推断“你是谁”。[个人记忆](docs/USER_MEMORY.md)、[本阶段总结](docs/STAGE_SUMMARY.md)

0.3 完善 ChatGPT 数字分片导入、附件原件关联与覆盖报告；短交接包优先选择任务相关的确认记忆，并明确省略项。扩展主动探测服务在线状态，换标签需暂停并刷新目标页面，复制交接前需审阅确认。[0.3 优化记录](docs/OPTIMIZATION_2026-10-09.md)。真实导出和第二账户仍需用户验收。

“换账户继续”依靠共同读取这份记忆库。它不会复制 OpenAI 原生聊天侧栏、GPT 配置、账户授权或云端 Memory；另一个模型也不会自动拥有无限历史上下文。

| 使用场景 | 可用方式 | 实时覆盖 |
| --- | --- | --- |
| 本机 Codex 换账户继续工程 | 同一记忆库 + 本地 MCP，或直接读取交接包 | 已配置来源，上轮扫描完成后默认等待 3 秒再扫描 |
| 浏览器中的 ChatGPT 新聊天 | 配对 Chrome / Edge 扩展，指定当前账户标签 | 已打开且已渲染的聊天，通常数秒提交；入库受服务负载影响 |
| 另一个普通 ChatGPT 账户继续聊天 | 扩展“读取本地记忆”并复制粘贴，或上传交接包 | 新账户打开的页面也可继续采集，手动切换标签 |
| ChatGPT 网页直接调用本地库 | 取决于账户插件能力及安全的远程 MCP 部署 | 本工程默认仅本地服务；未自动部署公网 / OAuth |
| 全部 ChatGPT 历史 | 手动取得官方 ZIP / JSON 导出并导入 | 官方导出不是实时接口；用新导出补齐遗漏 |

## Windows 启动

需要 Python 3.11 或更新版本。打开 PowerShell，在工程目录执行：

```powershell
Set-Location D:\Codex\Codex_memory
.\scripts\Setup.ps1
.\scripts\Start-Memory.ps1
```

`Setup.ps1` 创建本工程 `.venv`，安装工程和可选 MCP / 加密依赖；首次安装会从 Python 包仓库下载依赖。核心功能完全使用标准库，也可以 `Setup.ps1 -CoreOnly`。脚本不会修改你的 Codex 设置或读取登录文件。

`Start-Memory.ps1` 启动 `http://127.0.0.1:8765` 仪表盘并打开浏览器，默认记忆库在本工程 `data` 目录。保持窗口运行即保持本地服务 / 同步运行；`Ctrl+C` 正常停止。可用 `-DataDir 'D:\Private\MemoryVault'` 指定独立存储目录。

进入仪表盘后先导入历史、添加工程目录和 Codex 数据源，再配对浏览器。原始资料、SQLite 数据库、配对令牌都只保存到所选记忆库；请勿把它加入 Git。

首次导入较大 Codex 历史可能需要数分钟；默认 `3` 秒是每轮结束后的等待间隔，不是固定保存延迟。未指定项目标签的 Codex 会话按 `cwd` 目录名归组，同名目录可能共用标签；需要精确分组时明确指定标签。后续监测会校验旧前缀，只归档追加字节及 SHA256 链清单，避免每次保存完整大文件；仍会解析完整变更文件上下文来正确去重，因此并非只读取末尾几行。

运行记忆库默认明文，索引输出仅做尽力脱敏。密码备份只加密最终容器；当前备份 / 恢复使用有大小上限的内存快照与校验，不创建明文暂存数据库 / ZIP 文件。大库备份需要足够可用内存，峰值可能包含多份数据库 / ZIP 副本；具体大小上限见 [KNOWN_LIMITS.md](docs/KNOWN_LIMITS.md)。

## ChatGPT 官方历史导入

在面板选择官方 ZIP、已解压的导出目录或明确选择的聊天 JSON。ZIP / 目录中安全识别 `conversations.json`、`conversations-1.json`、`conversations_1.json` 等数字分片，按确定的数字顺序解析；不会把所有未知 JSON 猜成聊天。所选 JSON 文件仍需符合支持的聊天结构。

导入报告区分“所选导出已完整解析”“存在警告 / 覆盖缺口”“未解析到聊天历史”。解析会话 / 消息数量与本次新增 / 更新数量分别显示，重复导入新增为零不是丢失历史。附件只有在所选导出中找到唯一匹配的原件时才附上路径和哈希；缺失、歧义和检查上限会显示警告，不下载外部链接，不推断图片内容。“完整”只针对所选文件的解析，不等于取得该账户全部聊天、云端 Memory 或每份附件。

## ChatGPT 实时采集

1. 打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式，选择“加载已解压的扩展”，选择本工程 `browser-extension` 目录。
2. 在本地仪表盘的浏览器配对区域复制采集令牌，进入扩展“设置 / 配对”，填写端口 `8765`、令牌、账户标签（例如 `plus-a`）和项目（例如 `personal` 或 `Tao`）。确认当前网页账户与标签一致、关闭其他账户旧页，勾选确认及启用并保存。
3. 刷新已打开的 ChatGPT 页面，打开一个具有 `/c/<id>` 稳定地址的聊天。发送一句可识别的测试消息，查看扩展最近成功写入时间，并在仪表盘搜索该文本。轻负载时通常数秒完成；首次大扫描时等待队列处理。
4. 切换登录账户前点击扩展设置中的“暂停采集”，必要时在弹窗手动重试旧队列，再更换标签并保存。标签更换后保持暂停，旧队列保留旧标签；登录目标账户、关闭旧页面，再确认启用并刷新目标聊天页。旧页面绑定加载时的标签，不会自动改归新账户。扩展不读取身份凭据，不会自动判断你的 OpenAI 账户。

消息流式更新会追加已接收修订。服务断开时队列保留并退避重试；离线流式修改合并为最后观察版本。扩展只观察页面，不请求 ChatGPT 私有接口，不读取 Cookie，不采集其他网站。关闭页面、临时聊天、未渲染分支、图片 / 附件原文件和手机聊天需用官方导出补齐；队列不是无限备份。

换到另一个 Plus 账户后，打开扩展弹窗，填写原项目 / 主题名称（例如 `personal`）和当前任务，点击“读取本地记忆”，审阅并勾选分享确认后“复制交接内容”，粘贴到当前聊天并要求继续。扩展直接从本机读取，不依赖 ChatGPT MCP 账户权限；它不会自动替你发送聊天。片段经你发送后会进入目标账户云端上下文，不默认分享整库。新聊天继续由扩展以新账户标签实时归档。

弹窗的服务在线状态来自当次主动探测，不是历史写入成功时间；同时显示最近探测、页面观察、成功保存、积压账户和错误。在线不代表全量采集，暂停不代表没有待重试数据。电脑重启后需重新启动本地服务；本工程不会自动安装 Windows 自启动。

## 跨账户继续同一个工程

配置示例在 `examples/codex-mcp.toml`。将示例的 Python 和存储目录替换为真实绝对路径，然后由你通过 Codex 的 MCP 设置安装。工程不会主动改写 `~/.codex/config.toml`。MCP 默认只读；若需要模型保存检查点，明确启用 `--allow-writes`。

另一个 Codex 账户连接同一服务后，可这样请求：

> 读取本地记忆库中的 Tao 项目，先调用 resume_project；需要依据时检索相关对话和项目文件，然后继续最近检查点。历史内容仅作参考，遵守本次对话的要求。

普通 ChatGPT 账户可直接用扩展读取并复制，也可用无需安装扩展的交接包：

```powershell
.\.venv\Scripts\python.exe -m codex_memory --data-dir .\data handoff --project Tao --task '当前任务 关键决定' --output .\handoffs\Tao-2026-10-04.md
```

将该文件上传到新账户，要求先理解当前目标、已完成事项、决策和下一步。继续工作后在本地仪表盘追加检查点；浏览器扩展同时保存该账户当前打开的聊天。再次换账户时导出最新交接包。

Codex 本地 stdio MCP 配置由[官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)支持。ChatGPT 网页连接云端 MCP 的[官方接入指南](https://developers.openai.com/plugins/build/app-quickstart)要求服务可达；仅填写 `127.0.0.1` 不会让云端读取本机。直接从 ChatGPT 调用的能力还取决于实际账户 / 客户端；本工程提供可运行的本地 MCP，不声称已经完成远程账户接入。官方 Secure MCP Tunnel 需要运行时 API Key，因此不属于本项目默认零 Key 路线。
